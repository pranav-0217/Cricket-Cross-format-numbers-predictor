# Cricket cross-format predictor

Interactive companion to the poster *Cross-Format Cricket Performance Prediction
Using a Multivariate Mixed-Effects Model*. Enter a player's numbers in one format
and see the model's prediction for the other two, using the same k-NN latent
transfer evaluated in the paper.

Full code and analysis: https://github.com/pranav-0217/Cricket-Cross-format-prediction

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```
